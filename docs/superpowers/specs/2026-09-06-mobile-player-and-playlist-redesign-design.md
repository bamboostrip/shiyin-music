# 移动端歌单吸顶与播放页 QQ 音乐布局重构设计文档

## 1. 概述与背景
用户在移动端使用过程中提出两个核心视觉与交互优化点：
1. **歌单详情页（PlaylistDetailPage）**：在移动端向下滚动时，操作栏（`_ListStickyBar`）固定吸顶在 `SliverAppBar` 下方。由于吸顶栏此前写死了顶部 16px 圆角，导致与平直底边的 AppBar 拼接处出现了明显的三角空缺与突兀切口（见截图 1）。
2. **播放页（PlayerPage）移动端体验重构**：参考 QQ 音乐移动端主流布局与操作习惯：
   - 顶栏移除音质切换按钮与爱心按钮，使顶栏干净通透；
   - 顶栏居中显示页面指示器（当前页长条 `-`，另一页圆点 `·`）；
   - 歌曲页排布在右侧（Index 1），歌词页排布在左侧（Index 0），向右轻滑即可查看歌词；
   - 封面下方左侧放置大字号歌名、歌手与精致音质 Tag，右侧黄金拇指区放置爱心喜欢按钮；
   - 歌词与进度条之间增加横向快捷操作栏（收藏到歌单、音效、下载、评论）；
   - 点击专辑封面直接唤起歌曲详情与操作菜单（含音质调节、定时、倍速、分享等）；
   - 在专辑封面页面支持向下滑动手势（下拉阻尼/甩动）直接退出/返回播放页。

## 2. 歌单页面吸顶圆角动态渐变方案（方案 A）

### 2.1 涉及文件
- `lib/ui/pages/playlist_detail_page.dart`

### 2.2 实现细节
- 在 `playlist_detail_page.dart` 的 `_StickyHeaderDelegate` 中引入圆角/扁平化感知：
  - 监听列表滚动偏移量（`_scrollController`）与折叠阈值（`delta = _heroExpandedHeight - kToolbarHeight`）；
  - 展开态（`offset <= delta - 16`）：顶部圆角为标准 `16.0`（`AppRadius.lg`），具有微弱上浮阴影；
  - 吸顶过渡区（`delta - 16 < offset < delta`）：圆角线性从 `16.0` 插值渐变到 `0.0`，阴影透明度同步渐隐；
  - 完全吸顶态（`offset >= delta` 或 `overlapsContent == true` 或 `isDesktopFormFactor`）：顶部圆角固定为 `0.0`（纯平直角），无阴影，实现与 `SliverAppBar` 底边的无缝融合。
- `_ListStickyBar` 支持动态传入 `topRadius` 或根据吸顶状态平滑调整 `BorderRadius`。

## 3. 播放页面移动端 QQ 音乐布局与交互重构

### 3.1 涉及文件
- `lib/ui/pages/player_page.dart`
- `lib/ui/player/player_top_bar.dart`
- `lib/ui/player/poster_player.dart`
- `lib/ui/player/player_controls.dart`

### 3.2 页面架构与指示器契约
- **页面顺序与初始索引**：
  - `PageView` 子组件顺序调整为：
    - Index 0: `LyricPlayerPage`（歌词大屏页）
    - Index 1: `PosterPlayerPage`（封面播放主页）
  - `_pageController` 初始页面设为 `initialPage: 1`（默认进入封面播放主页）。
  - 用户在封面页上手势向右滑动（drag left-to-right）即可平滑切入 Index 0 歌词页；在歌词页向左滑回封面页。
- **顶栏（TopBar）重构**：
  - **左侧**：收起按钮 `Icons.keyboard_arrow_down_rounded`；
  - **中间**：页面状态指示器：
    - 左边代表歌词页，右边代表封面页；
    - 初始（封面页）：左为圆点 `·`（直径 4px），右为胶囊横条 `-`（宽 14px，高 3.5px）；
    - 滑到歌词页：左为胶囊横条 `-`，右为圆点 `·`；带有平滑补间动画；
  - **右侧**：更多按钮 `Icons.more_horiz_rounded`（点击唤出操作菜单）；
  - **移除**：顶栏不再显示爱心（下沉至下方）与音质 Pill（转为下方歌曲信息 Tag）。

### 3.3 专辑封面交互与下滑退出手势
- **点击封面唤起详情菜单**：
  - 在 `PosterPlayerPage` 中，封面外层增加 `GestureDetector` / `InkWell`；
  - 点击封面触发 `_showMoreSheet(context)`，弹出底部歌曲详情菜单（包含音质切换、定时播放、音效、添加到歌单等）。
- **向下滑动退出（Pull-Down Dismiss）**：
  - 在 `PosterPlayerPage` 顶部或主体包裹垂直手势检测（`GestureDetector` 或自定制下拉位移手势）：
  - 当手势向下拖拽超过阈值（如位移 > 80px 或向下甩动速度 > 800px/s）且当前不在向上拖动进度条/滑块时，触发 `Navigator.of(context).pop()` 优雅关闭播放页。

### 3.4 封面下方布局重构（参考 QQ 音乐）
在 `PosterPlayerPage` 封面下方，自上而下重组如下区块：
1. **歌曲信息与爱心行（Song Info & Favorite Row）**：
   - 水平 `Row` 布局，左右分栏：
   - **左侧 Expanded**：
     - 大字号歌曲标题（加粗，支持单行跑马灯溢出滚动）；
     - 歌手名字（点击进入歌手主页） + 精致的音质 Badge（如“标准 / 高品 / 无损 SQ”，点击直接唤起音质切换底栏）。
   - **右侧**：
     - 爱心喜欢按钮（`Icons.favorite_rounded` / `Icons.favorite_border_rounded`），触控靶心至少 44x44，拇指单手握持轻松直达。
2. **歌词预览行（Lyric Preview）**：
   - 优雅展示当前正在演唱的 1 行歌词（呼吸字效/高亮）；
   - 点击该行亦可平滑切换至左侧歌词页。
3. **快捷功能操作栏（Action Rail）**：
   - 在歌词与进度条之间，水平等宽均分 4 个常用交互图标：
     - `[➕ 收藏到歌单]`：打开自建歌单收藏底栏；
     - `[🎵 音效]`：如果支持音效则展示音效底栏入口（不支持时可展示定时播放）；
     - `[⬇ 下载]`：下载歌曲状态与操作；
     - `[💬 评论]`：酷狗歌曲评论入口，带图标与点击响应。
4. **进度条（Progress）**：
   - 保留带高潮标记的现代进度条。
5. **底部 5 键主控栏（Controls）**：
   - 播放模式（顺序/循环/随机）+ 上一首 + 播放/暂停大圆键 + 下一首 + 播放队列。

## 4. 平台兼容性保护
- **桌面端 / 车机模式横屏（Split Layout）不受影响**：
  - PC 端大屏和车机横屏模式使用独立的 `LandscapePlayerContent` / `DesktopPlayerBar`，其原有的双拼分栏及车机爱心控制逻辑保持不变；
  - 所有的重构仅对竖屏移动端（`!useSplitLayout`）生效，做到职责分离与精准升级。

## 5. 验证方案
1. **歌单吸顶验证**：
   - 手机端打开歌单，在顶部展开态观察卡片圆角为 16px；
   - 向上平滑滚动，观察吸附至 AppBar 过程中圆角动态归零，吸顶后完全平直接合，无三角空缺。
2. **指示器验证**：
   - 进入播放页默认位于封面页，顶栏中间显示 `· —`；
   - 向右滑手势切换至歌词页，顶栏动画平滑变为 `— ·`；向左滑回封面页恢复 `· —`。
3. **点击封面验证**：
   - 点击封面正中，弹出底部歌曲详情菜单，包含音质、定时、倍速等完整功能。
4. **下滑退出验证**：
   - 在封面页手势向下滑动，页面顺畅退出返回歌单/主页。
5. **下方信息与功能栏验证**：
   - 封面下方大标题、歌手、音质 tag 及右侧爱心正常显示与响应；
   - 歌词下方快捷栏 4 个按钮（收藏、音效/定时、下载、评论）均可正常点击并触发对应弹窗。
